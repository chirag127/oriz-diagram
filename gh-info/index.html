oriz-diagram

Diagram-as-code — a Mermaid live editor in your browser that exports SVG or PNG.

This is the project info page. It is not the app. Open the live tool at diagram.oriz.in.

What it is

Type a diagram in Mermaid text, watch it render instantly in a split code/preview layout, and export clean SVG (vector) or PNG (2x raster). Ships one-click templates for flowchart, sequence, ER, Gantt, and class diagrams. An optional AI helper turns plain English into Mermaid or fixes broken syntax.

Key features

  • Live split code/preview Mermaid editor, renders as you type, with zoom controls.
  • One-click templates: flowchart, sequence, ER, Gantt, class.
  • Export SVG (vector) and PNG (2x raster from the SVG).
  • Drag-drop a .mmd / .txt file to load it.
  • Optional AI: English to Mermaid, or fix-syntax. Editor still works if AI is down.
  • Last diagram remembered in localStorage; heavy renderer lazy-loaded.

Tech

  • Client-only Astro static build (React 19 islands, Tailwind v4, the mermaid library).
  • AI via @chirag127/oz-ai — g4f multi-provider failover, no API key.
  • PWA-installable.
  • 100% in-browser: no upload, no signup, no backend.
